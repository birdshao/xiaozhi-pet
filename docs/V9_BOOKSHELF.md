# V9 绘本书架（切片 1B / 方案 B1）

“讲故事”不再固定打开 `forest_friends`：卡上有 **两本及以上** 的书时，先进书架，用拨轮选书。

## 孩子看到的

- 一屏 3 本，封面是该书第 1 页的 1-bit 缩略图（4×4 抽样，≥4/16 黑点算黑，细线条不丢）。
- 拨轮上/下换书（首尾循环），按下打开，长按回首页。选到下一排时整屏刷新，同一排内只动选中框（局刷）。
- 系列书排在一起（`ShelfBefore`）；系列书封面下有小圆点，实心的是第几本。
- 最近读完的书（`recent_books`，最多 8 本）封面右上角有个勾。
- 傍晚（`DayPhase::Evening`）书架顶上有月亮：此时打开书就是睡前模式。
- 书架 ≥ 2 排时，底部有排数小圆点。状态栏角框和底部两角不画东西。
- 再次进“讲故事”时，选中框落在上一次读的那本（只存 RAM，重启后回到第一本）。

## 保持不变

- 卡上只有一本书（或没有书）：直接打开，和以前一样。只有一本但不是 `forest_friends` 时，直接打开那一本。
- 自测 `book <id>` 步骤指定了书：跳过书架扫描，直接打开（`v4_book_reader`、`v4_book_missing` 不受影响）。
- 书名按 `StoryPackFilePort` 的规则：3–63 个字符，小写字母、数字、`_`、`-`（首位不能是 `_`/`-`），不合规的文件不上架。
- 超过 24 本：先全部收集（最多 64 本）、按阅读顺序排序，再保留前 24 本，被丢掉的打 `SHELF_DROP` 日志。
- 扫描有 6 秒总时限，超时则用已扫到的书，缩略图缺的显示默认封面。
- 打开哪本书不写喜好，不写任何记忆；`BookFinished` 规则不变。
- 语音“讲故事”走同一个入口，所以同样先进书架。

## 实现

| 部分 | 位置 |
|---|---|
| 文件名过滤（跳过 `song_*` / `lullaby_*`）、排序、翻页、拨轮、缩略图抽样 | `book_shelf.{h,cc}`（纯逻辑，主机测试） |
| 书架画面数据 | `shelf_view.h`，画法 `shelf_draw.inc`（`scene_model.cc` 只加 include 和一行分派） |
| 新场景 | `SceneKind::Shelf`（追加在枚举末尾）；刷新规则：换排整屏，其余局刷 |
| 扫描 `/sdcard/books`、读系列信息和缩略图、换书 | `WaveshareStorySd::ScanShelf` / `SelectBook` |
| 讲述音频换书 | `FreertosStoryPcmWorker::RequestBook`（在音频任务里重开文件；`Start` 允许先不带书） |
| 接线 | `p1_integrate.py` 的故事段：`StoryPhase`（Pick / Shelf / Opening / Book） |

SD 读取不在输入任务里做：扫描在 Pet 模式启动时（和旧的打开默认书同一处），选书时由一个短任务
`pet_shelf` 在持有屏幕锁的情况下切换，期间书架留在屏幕上、拨轮不响应。

## 真机验证清单（不刷机，由主会话统一核对）

1. 卡上放 `forest_friends.kpb` + `reader_test.kpb`（+ 分支书、系列书若干），选“讲故事”：先出书架。
2. 日志：`PET_SHELF_SCAN books=N ms=…`（看扫描耗时，书多时最久）、`PET_SHELF_OPEN`、`PET_SHELF_VIEW`、
   `PET_SHELF_PICK book=… ok=1`、随后 `PET_BOOK_OPEN`。
3. 封面缩略图是否看得出是哪本书；选中框粗细、小圆点、勾、月亮是否清楚；局刷有没有残影。
4. 选书到第一页出画的耗时；读完回到首页再进，选中框是否在上一本。
5. 卡上只放一本书：不出书架。跑 `v4_book_reader`、`v4_book_missing`、`v9_shelf`。
6. 拨轮在“正在打开”时乱按，不会卡死或重复打开。

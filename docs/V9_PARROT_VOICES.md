# V9 鹦鹉学舌变声（切片 1D / S1）

孩子进入鹦鹉后，先用拨轮选声音，再照旧按住拨轮中键说话、松开回放。

## 玩法

| 位置 | 拨轮 | 效果 | 算法（都在 `ParrotSession::Render()` 里现算） |
|---|---|---|---|
| 0 鹦鹉 | 默认 | 高、快 | 重采样，读取速度 ×1.30 |
| 1 花栗鼠 | 下拨 1 格 | 更高、更快 | ×1.55 |
| 2 大熊 | 2 格 | 低沉、慢 | ×0.75 |
| 3 机器人 | 3 格 | 嗡嗡的机器声 | 原速，乘 70 Hz 三角波载波（环形调制） |
| 4 回声 | 4 格 | 说完后再响两遍 | 原速，叠加 180 ms 后 ×1/2、360 ms 后 ×1/4 的两份拷贝，尾巴多 360 ms |
| 5 小房子 | 5 格 | 按中键回家 | 不录音 |

- 拨轮上、下都能转，会循环。重新进入鹦鹉从第 0 个开始；同一次进入里，录完一段选择不变。
- 录音中拨轮无效。回放中拨轮 = 立刻停下、回到选择界面（以前是直接回首页）。
- 画面：团团戴对应的小帽子（羽毛、橡果帽、熊耳、天线、声波圈）。右边卡片是大图，下面一排 6 个点（5 个声音 + 小房子），选中的带圈。录音和回放时不显示这一排，大图保留。

## 隐私（一条没放松）

- 变声**没有第二块缓冲，也没有滤波状态**：回声直接从同一段录音里往前读，环形调制只用采样序号算载波。`ParrotSession` 整个对象 72 字节，没有新增指针或数组。
- 仍然没有新头文件、没有堆分配、没有文件/网络/日志。只有 `Feed()` 写录音缓冲，`Render()` 只读（`tests/test_v8_parrot_privacy.py` 新增断言检查这一点）。
- 清零出口不变：最后一块播放后、`Interrupt`、`Close`、仲裁拒绝、过短录音、析构，现在加上「回放中拨轮停止」。
- 板子日志新增 `PET_PARROT_VOICE voice=N`（只有声音编号）和 `PET_PARROT_STOP`，不含音频。
- 选择的声音不入账本、不记忆、不上传。

## 开销核算（ESP32-S3，240 MHz）

**RAM**

| 项 | 大小 |
|---|---|
| 录音缓冲（原有，PSRAM） | 5 s × 16 kHz × 2 B = 160,000 B，**不变** |
| `ParrotSession` 对象 | 72 B（原有字段加 3 个整数） |
| 回放暂存块（栈） | 480 × 2 B = 960 B，不变 |
| 变声新增 | **0 B 堆 / 0 B 缓冲**；`Render()` 栈上只多几个 32 位局部变量 |

**CPU**（主机上实测每个输出样本的耗时，板子上是估算，**没有在真机上测过**）

| 声音 | 主机 x86 | 每输出样本的相对成本 | 估算板子占用 |
|---|---|---|---|
| 鹦鹉 / 花栗鼠 / 大熊 | 2.5 ns | 1 次插值 + 增益（有 64 位乘） | 约 60 周期 |
| 机器人 | 3.6 ns | 再多一次整数乘法 | 约 90 周期 |
| 回声 | 5.9 ns | 3 次插值 | 约 200 周期 |

- 输出 24 kHz，回声最坏：24,000 × 200 ≈ 4.8 M 周期/秒，约占**单核的 2%**。LX7 没有 64 位硬件乘，所以这里按 64 位乘 20–30 周期估的，偏保守。
- 回放任务 `pet_parrot` 按实时速度送数据（队列满就等），变声不会让它跑不过实时。栈 4096 B 不变。
- 回放最长：大熊 5 s 录音 → 6.67 s；回声 5 s → 5.36 s。

## 真机上怎么验证

1. 刷机后进玩菜单的鹦鹉（语音“玩游戏”→ 找鹦鹉）。画面是鹦鹉卡 + 一排点，下拨一格应该变成花栗鼠，团团头上换帽子。
2. 每种声音各录一句「你好团团」：花栗鼠最尖、大熊最低沉且更长、机器人有明显嗡嗡声、回声说完后还响两遍、鹦鹉居中偏高。
3. 回放中拨一下轮：声音立刻停，回到选择界面，串口出现 `PET_PARROT_STOP`。
4. 转到小房子（最后一个点）按一下中键：回首页，串口**没有** `PET_PARROT_REC armed=1`。
5. 串口里 `PET_PARROT_VOICE voice=N` 只有编号；全程不应有写 SD 卡、联网的日志。
6. 自测脚本 `tools/selftest/v9_parrot_voices.pettest`（菜单步数要在 1A 合并后改一下）。

## 对旧自测的影响

`tools/selftest/v8_sound_routines.pettest`：鹦鹉里原来「转一下拨轮就回首页」，现在转拨轮是选声音，改成「上拨一格到小房子，按中键离开」。别的步骤没动，刷新计数不变。

### 由本轮引出的修改（PR #44 后续提交）

1. **拨轮方向对调**：按孩子操作的方向，上 = GPIO6，下 = GPIO4，按下 = GPIO5。原理图的 Button_Up/Button_Down 是按板子自身方向标的。
2. **释放去抖**：松开后 120 ms 内再次按下视为同一次按住（时长从第一次按下算起）；短按/说话/哄睡事件因此延后 120 ms 发出。
3. 自检日志改为按 GPIO 编号输出，避免再与"上/下"语义混淆。

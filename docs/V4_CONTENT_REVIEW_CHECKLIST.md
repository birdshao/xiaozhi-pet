# 家长审核清单：制作一本 KPB2 绘本

这份清单给负责审核内容的大人用。工具只检查格式，**不会**判断内容是否适合孩子；`"approved": true` 和 `--reviewed` 是你签字确认“我亲自看过、听过”。格式细节见 [V4_KPB2_CONTENT_FORMAT.md](V4_KPB2_CONTENT_FORMAT.md)。

每本书审核一次；书里任何文件改动（换一张图、重录一句话）都要按受影响的部分重新审核，并把 `revision` 加 1。

## 1. 来源与授权

- [ ] 插画、文字、录音都是自己做的，或者有明确的使用授权（不是随手从网上下载的）。
- [ ] 用 AI 生成的文字或图片只当草稿，已经逐字逐图人工改过、看过。
- [ ] 字体（如果用 `render` 命令生成文字页）有合法授权。
- [ ] 录音里没有家人真名、住址、学校、电话等身份信息。

## 2. 每一页

- [ ] 文字适合 3–6 岁：没有吓人、暴力、歧视、危险模仿（玩火、爬窗、吃药等）的内容。
- [ ] 文字和朗读录音**逐句一致**，没有多读、漏读、错字。
- [ ] 亲耳听完整段录音：音量适中、没有爆音和刺耳的声音、结尾没有杂音；长度不超过 60 秒。
- [ ] 打开 `preview` 生成的 `pageNN_grey.png` 看灰度效果：主要形象清楚，细线没有糊掉，深灰和黑能分清。
- [ ] 打开 `pageNN_mono.png` 看黑白回退效果：即使只有黑白，画面也认得出来（现在的板子先显示这张）。
- [ ] 页面上的文字孩子不认识也没关系，但画面本身要能讲清这一页的意思。

## 3. 每一道题

- [ ] 题目和本页内容有关，一句话能听懂；题干录音与文字一致，不超过 15 秒。
- [ ] 2–3 个选项，每个都有清楚的**图标**和**选项名录音**（孩子不识字，靠图标和声音选）。
- [ ] 打开 `pageNN_qK.png`：图标没有挡住画面重点；图标之间分得开；黑框是拨轮选中时的高亮位置。
- [ ] **知识题**（写了 `answer`）：正确答案确实正确、没有歧义；答错时的反馈是温和的（不批评、不扣分）。
- [ ] **喜好题**（写了 `like_topic`）：问的是孩子的喜好，没有对错；不能问身份、家庭、隐私（“你家住哪”“爸爸叫什么”）。
- [ ] 喜好题里标了 `"like": true` 的选项，才会被团团“记住”；像“都喜欢”“不知道”这样的选项不要标 `like`。
- [ ] 打开旁路清单 `*.manifest.json`，确认每个选项的 `writes_like` 和你想的一样。
- [ ] 如果开了 `voice_answer`：说出选项名只会得到即时回应，**不会**写进记忆，这是设计如此。

## 4. 编译与核对

```
python -m tools.story_pack pack     --source my_book/book.json --output out/my_book.kpb --reviewed
python -m tools.story_pack validate --package out/my_book.kpb
python -m tools.story_pack preview  --package out/my_book.kpb --output out/preview
```

- [ ] `pack` 没有报错；看过 `preview` 里**每一张**图。
- [ ] `validate` 输出 `PACKAGE_VALID KPB2 pages=… questions=…`，页数和题数与预期一致。
- [ ] `book.json` 里填了自己的名字或称呼作为 `reviewer`（只记在电脑上的清单里，不会进设备）。
- [ ] `content_id` 每本书唯一，以后修订同一本书保持不变；`revision` 每次修订加 1。
- [ ] 保存好 `*.manifest.json`（里面有整包 SHA-256）。以后发现卡上的文件和它对不上，就不要用。

## 5. 放到卡上

- [ ] 只把 `.kpb` 文件复制到 FAT32 TF 卡的 `/books/` 目录；不要把源文件、草稿放上去。
- [ ] 第一次在设备上打开时大人在旁边：翻完每一页、答一遍每道题，确认声音大小合适。
- [ ] 不用别人给的、来历不明的 `.kpb` 文件。校验和（CRC）只能发现文件坏了，**不能**证明内容安全或经过审核。

## 6. 记住的东西可以删

团团只记住喜好题里拨轮选中的答案（主题 + 选项编号），不记录声音。按设计家长可以查看并一键清空（设备家长入口和家长面板的这部分还在开发中，见 V5-05、V6-06）。

## 7. 分支书和系列（V8）

- [ ] 分支书：每条路都读一遍，各自能走到结局；选路题没有“对错”；“睡前模式走第一个选项”的那条路本身是完整的故事。
- [ ] 系列：同一系列的 `series.id` 相同、`index` 连续、`next_content_id` 指向下一本，最后一本为 0。
- [ ] 睡前模式：晚间在设备上整本试听——低对比度画面看得清、自动翻页节奏合适、结尾不突然。

见 [V8_BOOKS.md](V8_BOOKS.md)、[V8_STORY_REVIEW.md](V8_STORY_REVIEW.md)。

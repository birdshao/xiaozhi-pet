# 详细开发计划：xiaozhi-pet

**版本**：v0.2 / 2026-11-02（按实物硬件重做）  
**状态**：规划。已完成的 P0–P4 代码保留复用，后续按 V 阶段推进。  
**路线不变**：小智开源 ESP32 固件 + 自建小智 Python 语音服务 + 独立 PetLearning 服务；设备端本地优先。

## 0. 为什么重做

v0.1 假设板上只有 BOOT/PWR，交互全靠 BOOT 多击，IMU/RTC/SD 都是"待确认"。2026-11-02 核对微雪官方资料后确认：板上有**三向拨轮、QMI8658 姿态、PCF85063 时钟、SHTC3 温湿度、TG28 电源管理（锂电/充电/定时开机）、4 级灰度电子纸**。这些能力足以支撑：

- 用拨轮代替多击，3 岁孩子也能操作；
- 宠物有真实作息（时钟 + 定时开机 + 断电保留画面）；
- 体感互动（拿起、轻摇、倾斜、扣下）和环境感知；
- 灰度插画绘本、页内选择题；
- 结构化的个性与记忆。

产品与架构见 [PRD v0.2](PRODUCT_REQUIREMENTS.md)、[架构 v0.2](ARCHITECTURE.md)。

## 2. 阶段总览

```text
V0 方案与硬件资料冻结（本次）
 └─> V1 硬件能力验收（自检固件）
      ├─> V2 交互骨架：拨轮 + 新首页 + 语音播报 + 睡觉流程
      │    └─> V3 作息与电源：RTC/定时开机/浅睡眠/低电量
      │         └─> V4 体感、环境与内容互动
      │              └─> V5 个性与记忆
      └─> V6 语音深化与家长控制（可与 V4/V5 并行）
                └─> V7 稳定性、OTA、外壳与儿童安全验收
```

**MVP 定义**：V2 + V3 完成 = "离线宠物 MVP v2"（可替代旧 P2 MVP）。V5 完成 = "个性宠物 beta"。V7 才是长期试用版。

## V1：硬件能力验收

**目标**：把每项硬件能力变成真机数据。做一个"自检页"（DIAG 场景）随宠物固件发布，通过 OTA1 试验流程上板。  
**依赖**：V0。  
**交付物**：`docs/hardware/V1_HARDWARE_ACCEPTANCE.md`（含数据表、照片/视频说明）。

| ID | 任务 | 验收证据 |
|---|---|---|
| V1-01 | 拨轮三向：方向与 GPIO4/5/6 对应、去抖、长按、自动重复 | 第 1 轮已完成方向（上 = 6、下 = 4；2026-11-07 按用户要求对调为上 = 4、下 = 6）与抖动发现；待去抖后复测 100 次无漏/误 |
| V1-02 | I²C 扫描：0x18/0x34/0x51/0x6A或0x6B/0x70 全部应答 | 扫描结果 |
| V1-03 | QMI8658：读 ID、静置噪声、拿起/轻摇/扣下的原始曲线；INT2 中断 | 数据 + 阈值初值 |
| V1-04 | PCF85063：读写时间、断电（有/无备份电池）保持、闹钟中断 | 记录 |
| V1-05 | **RTC 闹钟定时开机**：PMIC 关机后由闹钟开机，读唤醒原因 | 3 次成功率记录 |
| V1-06 | TG28：电量%、电压、充电状态、VBUS；关机电流（如有条件） | 读数表 |
| V1-07 | SHTC3：读数与板载发热偏差（开机 0/10/30 分钟对比） | 偏差表 |
| V1-08 | 电子纸：1-bit 局刷耗时（不同区域）、快刷、全刷、4 灰度刷新耗时与残影；N 次局刷后的残影 | 耗时表 + 照片 |
| V1-09 | 浅睡眠：拨轮/BOOT/PWR/姿态唤醒延迟与可靠性；浅睡眠电流 | 记录 |
| V1-10 | 麦克风 RMS 包络：吹气、拍手、说话、环境噪声的区分度 | 数据 |
| V1-11 | GPIO39 共用确认（功放 vs 姿态 INT1）；PWR 键在 GPIO1 的电平行为 | 结论 |
| V1-12 | 小智原版 300 s 自动关机在宠物模式下的行为 | 记录 |

**Gate V1**：上述每项有真机结论（可以是"不可用"）；阈值初值、刷新耗时、唤醒方案据此冻结。

## 5. 完成定义（DoD，不变）

- 代码/配置/文档入库，记录上游 commit；
- 纯 C++/Python 逻辑有自动测试；硬件相关附真机步骤与日志；
- 出错、断网、低电量、缺 TF 卡时行为明确；
- 无硬编码密钥、无未审核儿童内容、无原始录音；
- 数据/协议变化有 schema 版本和迁移测试；
- 改动上游文件时说明范围和合并风险；
- 任何写 Flash 的真机步骤逐步获得授权并留记录。

## 6. 风险登记

| 风险 | 后果 | 预案 |
|---|---|---|
| 拨轮不适合幼儿手指 | 操作困难 | 外壳加大拨轮帽；语音命令备选 |
| 定时开机不可靠 | 作息失效 | 退化为浅睡眠定时器 + 按键开机 |
| 灰度刷新太慢 | 翻页体验差 | 绘本可选 1-bit 快刷版本 |
| 姿态误报 | 莫名其妙"醒来" | 阈值调优，家长可关 |
| NVS 空间不足 | 记忆写失败 | 有界记忆 + 服务端长期存储 |
| 小智上游改动板卡代码 | overlay 失效 | overlay 只锚定少量位置 + CI 合约测试 |
| 电池/外壳安全 | 人身风险 | V7 不通过禁止儿童日常使用 |

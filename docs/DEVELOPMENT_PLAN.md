# 详细开发计划：xiaozhi-pet

**版本**：v0.3 / 2026-11-08（按 main `5bda7c0` 更新状态）  
**原始规划**：v0.2 / 2026-11-02（按实物硬件重做）  
**路线不变**：小智开源 ESP32 固件 + 自建小智 Python 语音服务 + 独立 PetLearning 服务；设备端本地优先。

## 0. 为什么重做

v0.1 假设板上只有 BOOT/PWR，交互全靠 BOOT 多击，IMU/RTC/SD 都是"待确认"。2026-11-02 核对微雪官方资料后确认：板上有**三向拨轮、QMI8658 姿态、PCF85063 时钟、SHTC3 温湿度、TG28 电源管理（锂电/充电/定时开机）、4 级灰度电子纸**。这些能力足以支撑：

- 用拨轮代替多击，3 岁孩子也能操作；
- 宠物有真实作息（时钟 + 定时开机 + 断电保留画面）；
- 体感互动（拿起、轻摇、倾斜、扣下）和环境感知；
- 灰度插画绘本、页内选择题；
- 结构化的个性记忆。

产品与架构见 [PRD](PRODUCT_REQUIREMENTS.md)、[架构](ARCHITECTURE.md)。

## 5. 完成定义（DoD，不变）

- 代码/配置/文档入库，记录上游 commit；
- 纯 C++/Python 逻辑有自动测试；硬件相关附真机步骤与日志；
- 出错、断网、低电量、缺 TF 卡时行为明确；
- 无硬编码密钥、无未审核儿童内容、无原始录音；
- 数据/协议变化有 schema 版本和迁移测试；
- 改动上游文件时说明范围和合并风险；
- 任何写 Flash 的真机步骤逐步获得授权并留记录。

## 6. 风险登记

| 风险 | 后果 | 预案 |
|---|---|---|
| 拨轮不适合幼儿手指 | 操作困难 | 外壳加大拨轮帽；语音命令备选（已可用） |
| 定时开机不可靠 | 作息失效 | 退化为浅睡眠定时器 + 按键开机 |
| 灰度刷新太慢 | 翻页体验差 | 绘本可选 1-bit 快刷版本 |
| 姿态误报 | 莫名其妙"醒来" | 阈值调优，家长可关 |
| NVS 空间不足 | 记忆写失败 | 有界记忆 + 原子账本 + 服务端长期存储 |
| 小智上游改动板卡代码 | overlay 失效 | overlay 只锚定少量位置 + CI 合约测试 |
| 开放问答内容不当 | 儿童接触不适宜内容 | S6 三道开关、输出审核，默认关闭，家长可控 |
| 电池/外壳安全 | 人身风险 | V7 不通过禁止儿童日常使用 |

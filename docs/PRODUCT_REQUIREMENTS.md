# 产品需求文档（PRD）

版本：0.2（按实物硬件重做）｜日期：2026-11-02｜状态：**方案稿，待硬件逐项验收与家长试用**

> v0.1 按"只有 BOOT/PWR、硬件能力未知"设计，交互只能靠 BOOT 单击/双击/三击。2026-11-02 已按微雪官方手册、官方 ESP-IDF 示例和原理图核对实物配置（见 [硬件基线 §9](hardware/BOARD_BASELINE.md#9-官方资料核对的完整硬件配置2026-11-02)），本版围绕真实硬件重做交互、内容与宠物个性。

## 1. 产品定义

- 名称：xiaozhi-pet（宠物名由家长设置，文档示例"团团"）。
- 对象：3–5 岁儿童，不识字、发音不完整、注意力短、不理解 AI 能力边界；家长全程可控。
- 硬件：微雪 ESP32-S3-ePaper-3.97，带三向拨轮、BOOT、PWR、麦克风/喇叭、姿态传感器、时钟芯片、温湿度传感器、电源管理（锂电/充电）、TF 卡、Wi-Fi/BLE。
- 价值：**一只摸得着、会作息、记得你、陪你读书玩耍的电子纸宠物**。陪伴 + 轻养成 + 趣味学习；不是心理顾问、考试工具，也不替代家长和同伴。

## 2. 产品原则（强约束）

1. **儿童安全先于娱乐性**：开放聊天默认关闭或家长陪同；可发声的文本先审核后播放，审核不可用时只播固定话术。
2. **程序管动作、模型管语言**：翻页、喂食、奖励、作息、音量、开关麦克风都由确定性代码执行。
3. **离线完整可玩**：宠物、作息、绘本、小游戏、体感互动全部离线可用；联网只增加语音聊天和内容同步。
4. **温和养成**：无死亡、饥饿惩罚、离开会难过、连续签到惩罚、排他亲密或要求保密。
5. **低刺激、可预期**：电子纸只做离散画面和小区域局刷；声音为主引导；每次操作都有即时声音反馈。
6. **不识字也能用**：每个可选项都有图标 + 语音播报；不要求孩子看文字。
7. **隐私最小化**：不存原始录音；麦克风本地"吹气/拍手"只算音量包络，不录音；记忆只存结构化、家长可见可删的条目。
8. **可迁移**：业务不依赖某家 LLM、官方云或语音服务端内部数据库。

## 3. 硬件能力 → 交互设计

| 硬件 | 孩子能做什么 | 宠物怎么回应 | 约束 |
|---|---|---|---|
| **三向拨轮**（上/下/按下） | 上下拨选东西、翻页、选答案；按下确认 | 选中项高亮 + 语音读出名字；确认时宠物做动作 | 孩子主要操作件；拨动要有声音反馈 |
| **BOOT 键** | "和团团说话"（按一下开始/结束） | 进入"在听"表情；听完思考、回答 | 仅语音用；开放聊天关闭时只走固定命令和审核内容 |
| **PWR 键** | "哄团团睡觉" | 画面换成熟睡的团团，然后真正关机；画面断电保留 | 单击不再直接关机：先显示睡觉画面并可取消 |
| **姿态传感器 QMI8658** | 拿起、轻轻摇、倾斜、扣过来 | 拿起醒来打招呼；轻摇咯咯笑/晕乎；倾斜滚小球游戏；扣下躲猫猫 | 只奖励"轻"动作；剧烈摇晃不加分并温和提示；可关闭 |
| **时钟芯片 PCF85063** | 不需要操作 | 早上醒来问好、午睡、晚上犯困、讲睡前故事；安静时段离线生效 | 时间来自家长设置或联网校时；掉电有备份电池座 |
| **温湿度 SHTC3** | 不需要操作 | "今天有点热，团团想喝水"；冷了戴围巾（换装） | 只做生活小常识，不做健康判断 |
| **电源管理 TG28** | 插上充电 | 团团"在吃电"；电量低时打哈欠，提醒找大人充电 | 电量低优先保存状态 |
| **电子纸 800×480** | 看 | 1-bit 局刷做表情、选择高亮；4 级灰度做插画书页、宠物肖像；断电画面保留 | 局刷后定期全刷去残影；不做动画 |
| **麦克风** | 说话；对着吹气、拍手 | 吹蜡烛、吹泡泡、拍手节奏小游戏 | 本地只算音量，不录音、不上传 |
| **喇叭** | 听 | 音效、宠物短句、绘本朗读、儿歌 | 家长音量上限；安静时段降音 |
| **TF 卡** | 家长插卡 | 新绘本、新游戏、新装扮、新声音包 | 只读，只认审核过的包 |
| **Wi-Fi** | 不需要操作 | 联网时可语音聊天、同步内容和记忆 | 断网自动降级 |

## 4. 孩子的操作模型

一套规则贯穿所有页面，3 岁也能学会：

| 动作 | 含义 |
|---|---|
| 拨轮上 / 下 | 换一个（选择项、书页、答案） |
| 拨轮按下 | 就要这个（确认） |
| 拨轮长按 | 回家（回首页） |
| BOOT 按一下 | 和团团说话 / 说完了 |
| PWR 按一下 | 哄团团睡觉（再按拨轮取消） |

- 每次选中都播放该项的名字（本地录音），不依赖识字。
- 不使用双击、三击这类幼儿难以掌握的手势；BOOT 多击只保留给开发调试。
- **家长入口**：同时按住 BOOT 和拨轮按下 5 秒；进入后由家长在屏幕上操作，30 秒无操作自动退出。

## 5. 场景与界面

### 5.1 首页（HOME）

```
┌──────────────────────────────────────────────┐
│ 07:42  ☀ 24°C      🔋████  📶      (状态栏) │
│                                              │
│              [ 团团 肖像区 ]                  │
│            （表情局刷区域）                   │
│                                              │
│   💬聊天   📖故事   🎲游戏   🥕喂食   🌙睡觉   │  ← 动作条，拨轮选择
│ "团团想听故事！"            （一行提示/字幕）  │
└──────────────────────────────────────────────┘
```

- 动作条 5 个大图标，拨轮上下移动高亮，按下进入。高亮和表情只局刷对应区域。
- 状态栏：时间（RTC）、温度（SHTC3）、电量/充电、网络、安静时段图标。
- 团团会根据作息、天气、最近活动主动"提议"（提示行 + 一句语音），但不催促。

### 5.2 其他场景

| 场景 | 内容 | 拨轮 | 刷新 |
|---|---|---|---|
| 互动（PET） | 喂食、梳毛、换装、玩球 | 选物品/动作，按下执行 | 表情局刷 |
| 绘本（READER） | 4 级灰度书页 + 朗读 + 页内小问题 | 上/下翻页，按下"再读一遍"或回答 | 每页全刷（灰度） |
| 游戏（GAME） | 猜动物、找不同、数数、颜色、倾斜滚球、吹蜡烛 | 选答案 | 局刷 |
| 聊天（CHAT） | 团团表情 + "在听/在想/在说"图标 | 不需要 | 只换表情 |
| 睡觉（SLEEP） | 熟睡画面，断电保留 | 拨轮唤醒 | 一次全刷后关机 |
| 家长（PARENT） | 音量上限、安静时段、聊天开关、配网、电量、内容 | 家长操作 | 局刷 |
| 自检（DIAG，开发用） | 各硬件读数和事件 | — | 局刷 |

## 6. 宠物的一天（作息）

由 RTC 驱动，离线执行；家长可改时间表。

| 时段 | 宠物状态 | 行为 |
|---|---|---|
| 起床（如 07:00） | 醒来 | 时钟芯片定时开机，换"早安"画面并问好，随后回到省电 |
| 白天 | 活跃 | 正常互动；偶尔提议读书/游戏 |
| 午睡（可选） | 犯困 | 互动降为轻声；拨轮可叫醒 |
| 晚上（如 19:30） | 困了 | 提议睡前故事；不提议游戏 |
| 安静时段（如 20:30–07:00） | 睡觉 | 禁聊天、低音量；只能看睡觉画面或听已允许的睡前故事 |

## 7. 内容互动

- **绘本**：每页 4 级灰度插图 + 朗读音频 + 0–2 个页内小问题（拨轮选 2–3 个图标答案，可选语音回答）。读完得纪念贴纸。
- **知识小游戏**：规则化、离线：猜动物叫声、数一数、颜色/形状、大小比较、英语单词卡。题目来自审核内容包，不由模型即兴出题。
- **体感游戏**：倾斜滚球进洞、轻摇骰子、扣下躲猫猫、吹蜡烛/吹泡泡、拍手跟节奏。
- **生活小常识**：结合温湿度和时间（"天冷要穿外套"、"睡前刷牙"），由审核话术库生成。
- **儿歌/声音**：TF 卡声音包，安静时段只允许摇篮曲。
- **内容来源**：全部来自家长审核的 TF 内容包或服务端已批准内容；AI 生成只用于草稿，必须人工审核后打包。

## 8. 宠物个性与记忆

### 8.1 个性（确定性）

- 家长在初始化时选择一种性格底色：**好奇型 / 温柔型 / 活泼型**，再设置名字和声音。
- 性格是一组固定参数：口头禅、表情倾向、提议偏好（爱读书 / 爱运动 / 爱聊天）、反应台词库权重。设备端按参数从审核话术库选句，不依赖模型。
- 联网聊天时，性格参数作为角色设定传给语音服务；输出仍经审核。

### 8.2 记忆（分层、结构化、可删除）

| 层级 | 存哪里 | 内容 | 示例 | 保留 |
|---|---|---|---|---|
| 今日记忆 | 设备 NVS | 今天做过什么 | 喂过 2 次、读完《森林》、玩了滚球 | 每天归档 |
| 喜好记忆 | 设备 + 服务端 | 孩子**通过拨轮选择**表达的偏好 | 最喜欢的动物=大象、喜欢的颜色=蓝色 | 家长可查看/删除 |
| 成长记忆 | 设备 + 服务端 | 纪念卡、贴纸、装扮解锁、读过的书 | "第一次读完 5 本书" | 长期 |
| 家长备注 | 服务端 | 家长主动填写 | 昵称、生日（可选） | 家长管理 |

- 记忆只来自**结构化事件**（拨轮选择、完成的游戏、读完的书），不从自由语音里自动提取个人信息。
- 团团会"用"记忆：早上说"昨天我们读了大象的故事，今天还想读吗？"；拿起时说"你最喜欢的蓝色小球在这里"。话术来自审核模板 + 记忆槽位。
- 联网聊天时只给模型最小化摘要（喜好 + 今日活动），不给家长备注里的身份信息。
- 家长可一键清空所有记忆；清空后宠物回到"刚认识"状态，但性格与名字保留。

## 9. 语音交互

- **触发**：BOOT 按一下开始，再按一下或 6 秒静音结束。不做常驻唤醒词（避免误听，省电）。
- **两条通道**：
  1. 固定命令（"下一页"、"讲故事"、"团团睡觉"）→ 确定性意图 → 本地动作，不走 LLM；
  2. 开放问答（家长开启后）→ 审核 → LLM → 输出审核 → TTS。
- **绘本上下文**：在绘本页提问时，只带当前页审核文本作为上下文。
- **失败降级**：断网、审核失败、服务超时 → 播放本地固定话术并回到原场景。
- **屏幕联动**：只切换"在听/在想/在说"三种表情，不随字幕逐字刷新。

## 10. 家长控制

- 设备端家长入口（§4）：音量上限、安静时段、开放聊天开关、作息时间、Wi-Fi 配网、电量与充电信息、记忆清空、内容包列表。
- 服务端家长 API：策略同步、记忆查看/删除、内容审批、使用概览。
- 最低保护策略保存在设备本地，断网仍执行。

## 11. 功能优先级

| 功能群 | MVP（V1–V3） | 后续（V4–V6） |
|---|---|---|
| 操作 | 拨轮三向 + BOOT 说话 + PWR 睡觉；语音播报选项 | 家长入口完整菜单 |
| 宠物 | 首页动作条、6–8 种表情、喂食/梳毛/换装 | 更多装扮、场景 |
| 作息与电源 | RTC 作息、安静时段离线生效、睡觉画面 + 真关机、定时开机问好 | 低电量策略精调 |
| 体感 | 拿起唤醒、轻摇反应 | 倾斜滚球、躲猫猫、吹气/拍手 |
| 环境 | 温度显示 + 生活小常识 | 换装联动 |
| 内容 | 灰度绘本 + 朗读 + 页内选择题；猜动物 | 更多游戏、英语卡、儿歌包 |
| 个性记忆 | 三种性格底色、今日记忆、喜好记忆 | 成长纪念卡、记忆驱动话术 |
| 语音 | 固定命令 + 审核内容回答 | 家长开启的开放问答 |

**明确非目标**：实时动画/口型、自由上网、无人监督的情感陪伴、计步/健康判断、家居控制、常驻唤醒词、录音存储。

## 12. 质量目标（待实测定标）

- 拨轮操作 → 声音反馈 < 150 ms；→ 局刷高亮可见 < 1 s（实测后定）。
- 断电/关机不丢宠物状态和记忆；重复事件不重复奖励。
- 关机状态下靠 RTC 定时开机；待机/关机功耗与续航实测记录。
- 体感误触率：静置 1 小时误报 0 次；正常拿起识别率实测记录。
- 语音各阶段耗时分开记录，用家长同意的真实儿童语音测。

## 13. 待硬件验证的问题

1. 拨轮三向的手感、方向与 GPIO4/5/6 对应关系（原理图已标注，需真机确认）。
2. GPIO39 在原理图上同时标"功放控制"和"姿态中断 1"，需确认是共用还是二选一；姿态中断先只用 INT2（GPIO40）。
3. 关机后 RTC 闹钟能否经电源管理芯片把设备开机（官方示例代码有此用法，需真机验证）。
4. 浅睡眠下拨轮/BOOT/姿态中断的唤醒可靠性；深睡眠只能用 RTC GPIO（0–21）唤醒，姿态和时钟中断不在其内。
5. 4 级灰度全刷耗时、1-bit 局刷耗时、残影与全刷周期。
6. 小智原版 300 秒无操作自动关机与宠物作息的冲突处理。
7. 电池容量、续航、充电温升；外壳与儿童安全。

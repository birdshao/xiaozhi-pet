# 产品需求文档（PRD）

版本：0.1（方案冻结前草案）｜日期：2026-10-25｜状态：**待原型和家长验证**

## 1. 产品定义

- 名称：xiaozhi-pet（宠物名由家长设置，文档示例“团团”）。
- 对象：3–5 岁儿童，必须考虑不识字、发音不完整、注意力短、可能不明白 AI 的能力边界。
- 外形：微雪 ESP32-S3-ePaper-3.97 作为第一块原型板，800×480 黑白墨水屏；以后外壳需满足防拆、防小零件和电池安全要求。
- 价值：**陪伴式互动 + 轻量养成 + 趣味学习**，不是无人监督的心理顾问、教学考试工具，也不替代家长及真实同伴。
- 使用场景：桌面宠物、亲子读绘本、认识动物与自然、英语词汇、简单问答、睡前播放经审核的故事。

## 2. 产品原则（强约束）

1. **儿童安全先于娱乐性**：默认家长参与的开放聊天；关键内容先审核后播放，无法审核时不输出开放式模型回答。
2. **程序管动作、模型管语言**：翻页、喂食、奖励、限时、开关麦克风由确定性代码处理。
3. **离线可用**：断网保留宠物静态互动、菜单、已有故事和基本游戏；不承诺离线自由 AI 对话。
4. **温和养成**：没有死亡、惩罚、饥饿压力、因离开而悲伤、连续签到惩罚、诱导亲密排他或要求保密。
5. **低刺激显示**：静态情绪、间歇局刷、无高速动画；声音引导为主。
6. **隐私最小化**：默认不保存原始儿童录音；只存储必要的家长授权偏好与学习状态，可查看/删除。
7. **可迁移**：宠物业务不依赖某家 LLM、官方云或小智服务端内部数据库。

## 3. 使用角色与典型流程

| 角色 | 权限 | 典型操作 |
|---|---|---|
| 儿童 | 本地有限交互、家长允许的学习与语音 | 点击/按住说话、换场景、摸摸宠物、听故事 |
| 家长 | 网络/开放聊天授权、每日时长、内容库、记忆删除 | 启用离线模式、查看学习概览、导入教材 |
| 开发者 | 固件、服务端、回归、日志 | 升级、扩展适配器、诊断断网或刷新异常 |

### U1：从休息到互动

孩子拿起设备或按下按键 → 设备本地发出温和音效 → 墨水屏显示开心状态 → 可以选择“听故事/玩游戏/和团团聊天”。没有网络也要成立。

### U2：情境化 AI 问答

孩子在动物绘本第 2 页问“它为什么有长鼻子？” → 自建 ASR → 教材上下文查询 → LLM 适龄生成 → 输出审核 → TTS → 回复与表情协调；网络或审核失败时播放本地预设引导语，并可继续绘本。

### U3：可预期的养成

孩子选择“给团团一根胡萝卜” → 本地状态机判定且幂等更新 → 表情/音效即时反馈 → 异步同步 Python → 不联网也可完成。奖励主要是造型、贴纸、场景与纪念卡；不以孩子答错作为负面惩罚。

### U4：家长控制

家长设置允许时段和最长互动时间 → 设备在本地执行最小保护阈值，网络服务同步策略 → 到时自然结束并提示与家人活动 → 无网络仍遵守最近确认的策略。

## 4. 功能优先级与范围

| 功能群 | MVP（P1–P3） | 后续（P4–P5） |
|---|---|---|
| 宠物基础 | 5–8 个状态/静态表情、即时输入反馈、本地声音、持久化 | 换装、成长轨迹、场景解锁 |
| 互动 | 按键点击/长按、Wi-Fi 状态、休息/醒来 | IMU 互动、外接读卡/点读 |
| 语言 | 自建 ASR/LLM/TTS、固定角色、适龄回复、基础审核 | 更好的幼儿 ASR、受控多轮课程、有限个性化 |
| 学习 | 少量本地审核故事/简单猜动物 | 教材资源包、批量生成与审核、英汉启蒙、进度 |
| 家长管理 | 简易设置、关闭开放聊天、清除记忆 | 家长面板、内容白名单、导入与使用报告 |
| 可靠性 | 可断网运行、重启恢复、清晰错误反馈 | OTA、回滚、升级迁移、完整日志和 CI |

**明确非目标（第一阶段）**：实时逐帧动画、流畅口型同步、自由上网检索、独立使用的儿童心理陪伴、未经批准的家居设备控制、未验证的 OID 识别。

## 5. 交互状态与界面

- 首页（HOME）：主体宠物 + 简短提示 + 电量/网络；静态场景。
- 互动页（PET）：开心/疑惑/休息/惊喜等表情；喂食/玩耍等确定性动作。
- 学习页（LEARN）：书页图片、页码、两行以内的文案提示、音频播放状态。
- 对话页（CHAT）：维持宠物形象，显示“正在听/思考/说话”，避免每个 ASR 字符都触发墨水屏刷新。
- 家长页（PARENT）：受保护入口，儿童操作不应轻易开启网络功能。
- 错误/离线页：不用恐怖或指责性的提示，保留继续离线玩耍的入口。

事件示例：`PICKUP`、`PRESS_SHORT`、`PRESS_LONG`、`PET_FEED`、`VOICE_LISTEN_START`、`VOICE_REPLY_DONE`、`PAGE_NEXT`、`QUIET_HOURS_START`。

屏幕行为：UI 由自己的应用控制；每次状态变化先确定新场景/脏区，再由刷新队列执行。不能把 LVGL 的局部 invalidation 当作电子纸物理局刷已实现的保证。

## 6. 儿童安全与隐私

### 最低要求

- 统一输入路由：拒绝危险请求、隐私索取、成人内容及未授权控制命令。
- 输出审核：在播报前检查最终可发声文本；流式 TTS 不能绕过审核。
- 不提供可自由使用的浏览器、搜索、支付、家庭设备操作工具。
- 不说“只有我懂你/别告诉家长/我会难过/你不来我会生病”等依赖性表达。
- 不声称真实意识/真实情感；提醒孩子可以和家人或老师讨论。
- 家长可禁用开放式问答、删除持久偏好、管理教材和使用时间；保留简单物理停用路径。
- 不将真实姓名、详细地址、录音等信息纳入宠物“成长值”；敏感信息默认不保存。
- 外部 ASR/LLM/TTS 的数据处理条款须由家长知晓；禁止把开发日志当长期语音记录。
- 原型阶段由成年人监督；未完成安全验收前，不宣称可让幼儿独立使用。

### 对话体验

- 回答简短、具体、友好；每次控制提问数量；对听不清的幼儿发音先请求重复。
- 儿童提出危险行为、身体伤害或需要现实帮助时，引导立即找家长/可信成人，而非自作专家。
- 课程、故事、奖励的推荐规则不以增加使用时长或情感依赖为优化目标。

## 7. 质量目标（初拟，P0/P1 实测后定标）

以下是**待验证目标**，不是已达到的数据：

- 设备端事件（按键→可见反馈/音效）应优先即时响应；物理电子纸刷新另计并记录。
- 断网不会导致宠物状态丢失；重复事件不能重复给成长奖励。
- 语音 ASR/LLM/TTS 每阶段分别记录耗时；使用真实儿童口音/家长同意的测试集，不能只测成年人。
- 绘本播放中网络掉线不影响缓存页音频；云端会话与本地音频互斥。
- 用例覆盖：难以识别的低龄语音、安静时段、危险话题、断电恢复、长时间闲置。

## 8. 关键未决问题（先测后定）

1. 实物是否有可用的旋转拨轮？当前官方板级固件代码主要注册 BOOT/PWR 按钮，不应假设拨轮软件输入已具备。
2. IMU 的具体型号/总线映射、是否与现有音频/电源 I²C 共存，待 P0 读取证实。
3. 当前墨水屏驱动的局刷区域、残影与寿命策略是否满足宠物场景，待 P1 真机测试。
4. SD 接口引脚、文件系统与大文件播放、音频解码共存，待 P0/P4 验证。
5. 完整设备固件 + 资源分区 + 双 OTA 分区的 Flash 预算，待构建后以 map/partition 表核算。
6. ASR/LLM/TTS 提供商、费用和个人隐私要求，待 P3 对比后决定。
7. 商业化不是当前目标；如果将来销售，还需另行评估儿童产品安全、隐私和开源许可证要求。
